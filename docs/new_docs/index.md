## Overview

The Referral System is a web-based application that facilitates the management of medical referrals between healthcare facilities. It streamlines the process of patient referrals, ensuring efficient coordination and continuity of care.

### Key Features

- Patient referral management
- Facility coordination
- Status tracking
- Reporting and analytics
- User role management

### System Requirements

- PHP 8.1 or higher
- MySQL 5.7 or higher
- Composer
- Node.js and NPM
- Web server (Apache/Nginx)
