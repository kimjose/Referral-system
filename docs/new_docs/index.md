## System Overview

The Angaza Referral System is a comprehensive healthcare referral management system that facilitates the efficient transfer of patients between healthcare facilities. The system integrates with various healthcare information systems including:

- Master Facility List (MFL)
- Electronic Community Health Information System (eCHIS)
- Shareable Health Records (SHR)
- Health Information Exchange (HIE)
