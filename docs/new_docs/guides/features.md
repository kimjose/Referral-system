# Features

The Angaza Referral System provides a comprehensive set of features designed to streamline the healthcare referral process. This document outlines the main features and capabilities of the system.

## Core Features

### 1. Patient Management
- **Patient Registration**
  - Quick patient registration with essential details
  - Automatic patient ID generation
  - Duplicate patient detection
  - Patient history tracking

- **Patient Records**
  - Comprehensive medical history
  - Previous referrals tracking
  - Treatment history
  - Medication records
  - Lab results integration
