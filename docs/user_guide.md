# Angaza Referral System - User Guide

## Overview
The Angaza Referral System is a comprehensive platform for managing healthcare referrals between facilities and Community Health Units (CHUs). This guide will help you navigate and use the system effectively.

## Getting Started

### 1. System Access
1. Open your web browser and navigate to the system URL
2. Enter your username and password
3. Click "Login" to access the system

### 2. Dashboard Overview
The dashboard provides quick access to:
- Active referrals
- Pending tasks
- Recent activities
- System notifications

## Core Features

### 1. Facility Management

#### Viewing Facilities
1. Click "Facilities" in the main menu
2. Use filters to search by:
   - Name
   - County
   - Service type
   - Status

#### Adding a New Facility
1. Click "Add Facility" button
2. Fill in required information:
   - Facility name
   - Facility code
   - Address details
   - Contact information
3. Click "Save" to create the facility

#### Editing Facility Details
1. Find the facility in the list
2. Click the "Edit" button
3. Update the required information
4. Click "Save" to update

### 2. CHU Management

#### Viewing CHUs
1. Click "CHUs" in the main menu
2. Filter by:
   - Facility
   - Status
   - Location

#### Creating a New CHU
1. Click "Add CHU" button
2. Enter:
   - CHU name
   - CHU code
   - Associated facility
   - Location details
3. Click "Save" to create

#### Managing CHWs
1. Select the CHU
2. Click "Manage CHWs"
3. Add/remove CHWs as needed
4. Update CHW details

### 3. Referral Management

#### Creating a Referral
1. Click "New Referral"
2. Select:
   - Patient details
   - Referring facility/CHU
   - Receiving facility
   - Service required
3. Add any additional notes
4. Click "Submit Referral"

#### Tracking Referrals
1. Go to "Referrals" section
2. View status:
   - Pending
   - In Progress
   - Completed
   - Cancelled
3. Click on referral for details

#### Updating Referral Status
1. Open the referral
2. Click "Update Status"
3. Select new status
4. Add comments if needed
5. Click "Save"

### 4. Integration Features

#### MFL Sync
- Automatic daily sync at 01:00 AM
- Manual sync available:
  1. Go to "Integrations"
  2. Select "MFL"
  3. Click "Sync Now"

#### eCHIS Integration
- 15-minute interval sync
- View sync status:
  1. Go to "Integrations"
  2. Select "eCHIS"
  3. Check sync logs

#### SHR Integration
- 30-minute interval sync
- Monitor sync:
  1. Go to "Integrations"
  2. Select "SHR"
  3. View sync history

#### HIE Integration
- Hourly sync
- Check status:
  1. Go to "Integrations"
  2. Select "HIE"
  3. Review sync logs
