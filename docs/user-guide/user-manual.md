# User Manual

## Introduction

Welcome to the Referral System User Manual. This guide will help you understand how to use the system effectively.

## Getting Started

### Login
1. Navigate to the login page
2. Enter your email and password
3. Click "Login"

### Dashboard
The dashboard provides an overview of:
- Recent referrals
- Pending actions
- System statistics

## Managing Referrals

### Creating a Referral
1. Click "New Referral"
2. Fill in patient details
3. Select receiving facility
4. Add referral notes
5. Submit the referral

### Viewing Referrals
- Use the search bar to find specific referrals
- Filter by status, date, or facility
- Click on a referral to view details

### Updating Referral Status
1. Open the referral details
2. Click "Update Status"
3. Select new status
4. Add comments if needed
5. Save changes

## Facility Management

### Viewing Facilities
- Browse the facilities list
- Use filters to find specific facilities
- View facility details and statistics

### Facility Profile
- Contact information
- Services offered
- Staff members
- Operating hours

## User Management

### Profile Settings
1. Click your username
2. Select "Profile"
3. Update your information
4. Save changes

### Password Management
1. Go to Profile
2. Click "Change Password"
3. Enter current and new password
4. Save changes

## Reports

### Generating Reports
1. Navigate to Reports section
2. Select report type
3. Choose date range
4. Click "Generate"

### Available Reports
- Referral statistics
- Facility performance
- User activity
- System usage

## Troubleshooting

### Common Issues
- Login problems
- Referral creation errors
- Status update issues

- Contact system administrator
- Check FAQ section
