# Troubleshooting Guide

This guide provides solutions for common issues you might encounter while using the Angaza Referral System.

## Common Issues

### Login Problems
- **Can't log in**
  - Verify your credentials
  - Check your internet connection
  - Clear browser cache
  - Try a different browser

### Referral Issues
- **Can't create referral**
  - Check required fields
  - Verify patient information
  - Ensure provider is available
  - Check system status

### System Performance
- **Slow response times**
  - Check internet connection
  - Clear browser cache
  - Close unused tabs
  - Try refreshing the page

## Error Messages

### Common Error Codes
- E001: Authentication Failed
- E002: Invalid Input
- E003: System Unavailable
- E004: Database Error

### How to Report Issues
1. Note the error code
2. Record the steps to reproduce
3. Take a screenshot if possible
4. Contact support with details
