# Getting Started

Welcome to the Angaza Referral System! This guide will help you get started with using the system.

## Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- Internet connection
- Valid login credentials

## Quick Start

1. Access the system through your web browser
2. Log in using your credentials
3. Navigate to the dashboard
4. Start creating referrals

## Next Steps

- Read the [User Manual](user-manual.md) for detailed instructions
- Explore [Features](features.md) to learn about system capabilities
- Check [Troubleshooting](troubleshooting.md) if you encounter any issues

## System Requirements

### Browser Requirements
- Google Chrome (version 80 or higher)
- Mozilla Firefox (version 75 or higher)
- Microsoft Edge (version 80 or higher)
- Safari (version 13 or higher)

### Internet Connection
- Minimum 2 Mbps download speed
- Stable internet connection required
- Offline mode available for basic functions

### Device Requirements
- Desktop/Laptop: Windows 10/11, macOS 10.15+, or Linux
- Mobile: iOS 13+ or Android 9+
- Tablet: iPadOS 13+ or Android 9+

## First-Time Setup

### 1. Account Creation
1. Visit the system URL provided by your administrator
2. Click "Create Account"
3. Enter required information:
   - Full name
   - Email address
   - Phone number
   - Organization details
4. Create a strong password
5. Verify email address

### 2. Initial Login
1. Enter your email and password
2. Complete two-factor authentication if enabled
3. Set up security questions
4. Review and accept terms of service

### 3. Profile Setup
1. Upload profile picture (optional)
2. Complete contact information
3. Set notification preferences
4. Choose language preference

## Basic Operations

### 1. Creating Your First Referral
1. Click "New Referral" button
2. Select patient type:
   - New patient
   - Existing patient
3. Enter patient details
4. Choose facilities
5. Add service details
6. Review and submit

### 2. Managing Facilities
1. Access facility list
2. Use search and filters
3. View facility details
4. Update information

### 3. Working with CHUs
1. View CHU list
2. Add new CHU
3. Assign CHWs
4. Update status
