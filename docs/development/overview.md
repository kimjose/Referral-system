# Development Overview

This section provides an overview of the development process and guidelines for contributing to the Angaza Referral System.

## Introduction
The Angaza Referral System is built using modern web technologies and follows best practices for healthcare software development.

## Development Stack
- Frontend: React.js with TypeScript
- Backend: Node.js with Express
- Database: PostgreSQL
- Testing: Jest, Cypress
- Documentation: MkDocs

## Getting Started
1. Clone the repository
2. Install dependencies
3. Set up the development environment
4. Run the development server

## Development Guidelines
- Follow the coding standards
- Write tests for new features
- Update documentation
- Review code before submitting

Please read our [Contributing Guidelines](CONTRIBUTING.md) before starting development work.
