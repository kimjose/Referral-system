# Contributing Guide

Thank you for your interest in contributing to the Angaza Referral System! This guide will help you get started.

## Development Process

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Write tests
5. Submit a pull request

## Code Standards

### PHP
- Follow PSR-12 coding standards
- Use type hints
- Write PHPDoc comments
- Keep methods focused

### JavaScript
- Follow ESLint rules
- Use ES6+ features
- Write JSDoc comments
- Follow Vue.js style guide

### Git
- Write clear commit messages
- Use conventional commits
- Keep commits focused
- Rebase before submitting PR

## Testing

### PHP Tests
```bash
php artisan test
```

### JavaScript Tests
```bash
npm test
```

### Code Coverage
```bash
php artisan test --coverage
```

## Pull Request Process

1. Update documentation
2. Add tests for new features
3. Ensure all tests pass
4. Update changelog
5. Request review

## Documentation

### Code Documentation
- PHPDoc for PHP code
- JSDoc for JavaScript code
- Inline comments for complex logic

### User Documentation
- Update user guides
- Add API documentation
- Update changelog
- Add migration guides

## Communication

### Issues
- Use issue templates
- Provide reproduction steps
- Include error messages
- Add screenshots if relevant

### Discussions
- Use GitHub Discussions
- Be respectful
- Provide context
- Follow up on responses

## Getting Help

- Check documentation
- Search existing issues
- Join community chat
- Contact maintainers

By contributing to the Angaza Referral System, you agree that your contributions will be licensed under the project's license.
