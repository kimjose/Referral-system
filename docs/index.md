## System Overview

The Angaza Referral System is a comprehensive healthcare referral management system that facilitates the efficient transfer of patients between healthcare facilities. The system integrates with various healthcare information systems including:

- Master Facility List (MFL)
- Electronic Community Health Information System (eCHIS)
- Shareable Health Records (SHR)
- Health Information Exchange (HIE)

## Key Features

- **Patient Referral Management**
  - Create and track patient referrals
  - Real-time status updates
  - Automated notifications
  - Referral history tracking

- **Facility Integration**
  - MFL facility synchronization
  - Facility profile management
  - Service availability tracking
  - Capacity monitoring

- **Community Health Unit (CHU) Management**
  - CHU registration and management
  - Community health worker tracking
  - Service area mapping
  - Performance monitoring

- **Multi-System Integration**
  - MFL data synchronization
  - eCHIS integration
  - SHR health records
  - HIE data exchange
